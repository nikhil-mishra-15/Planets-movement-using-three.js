A simple 3D solar system simulation built with Three.js that allows you to control the orbital speeds of all 8 planets.
Features

-Sun at the center with realistic lighting
-All 8 planets with relative sizes and colors
-Adjustable orbital speeds for each planet using sliders
-Pause/Resume functionality
-Saturn with rings (simplified)
-Responsive design that works on mobile and desktop

--How to Use--

-Open the index.html file in any modern web browser

-Use the control panel at the bottom to:

 -Adjust planet speeds using the sliders
 -Pause/resume the animation with the button

-Watch as the planets orbit the sun at your chosen speeds!


--Planet Controls--

-Each planet has its own speed slider:
-Mercury (4.1x default speed)
-Venus (1.6x)
-Earth (1x - baseline speed)
-Mars (0.5x)
-Jupiter (0.08x)
-Saturn (0.03x)
-Uranus (0.01x)
-Neptune (0.006x)

--Technical Details--

-Built with Three.js
-Uses requestAnimationFrame for smooth animation
-Simple physics for orbital movement
-Responsive design with basic CSS

--Requirements--

-Modern web browser (Chrome, Firefox, Safari, Edge)
-Internet connection (to load Three.js from CDN)
